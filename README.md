# Inventory System

## Project Description
This is a simple inventory management system built with JavaScript. It runs in the console and helps manage products, stock, prices, and purchases.

## Features
- Find a product by ID
- Filter products by available stock
- Filter products by category
- Calculate total inventory value
- Check stock availability and product prices
- Add a new product
- Remove a product by ID
- Update product stock
- Simulate a product purchase
- Apply discounts to products by category
- Display an inventory summary

## Technologies
- JavaScript
- Node.js
- Git and GitHub

## How to Run
1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
node index.js
```

## Project Type
Console-based JavaScript project. No HTML, CSS, database, or external packages are required.
